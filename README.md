# oda-watch

평일 오전 8시·오후 4시(KST)에 아래 게시판의 새 글을 모아 PDF 보고서로 텔레그램에 보낸다.

| 사이트 | 확인하는 게시판 |
|---|---|
| EDCF | 입찰공고, 입찰예정사업, 입찰결과(수주업체 발표 포함), 공지사항, 보도자료 |
| 수출입은행 | 공지사항, 보도자료 |
| KSP | 입찰공고, 소식 |
| 나라장터 | 수요기관이 한국수출입은행인 입찰공고 (용역·물품·공사) |
| 해외건설협회 | 입찰공고, 공지사항, 보도자료, 국토교통 ODA, 최신정보, 건설뉴스 |
| 엔지니어링협회(ETIS) | 공지, 공고, 협회소식, 입법·행정예고, 임금실태·통계 중 해외사업 관련 글 |

- 이미 보낸 글은 `state/seen.json`에 기록해 다시 보내지 않는다. 주말·공휴일엔 건너뛰고 다음 보고에 몰아 담는다.
- 사이트 하나가 막혀도 나머지는 보고하고, 실패한 사이트는 보고서와 메시지에 표시한다.
- 나라장터 수요기관은 `sources.py`의 `G2B_DEMAND`, 엔협 해외사업 판별은 `overseas.py`(국가명·해외·ODA 등 낱말)
- PDF 한글 글꼴: GitHub에선 나눔고딕(fonts-nanum), 윈도우에선 맑은 고딕

## 설정 (GitHub Secrets)
- `TELEGRAM_BOT_TOKEN` — 텔레그램 봇 토큰. 대화방(chat_id)은 봇에게 말을 건 방을 자동으로 찾아 `state/chat_id.txt`에 기억 (`TELEGRAM_CHAT_ID` Secret이 있으면 그것을 씀)
- `G2B_API_KEY` — 공공데이터포털 조달청 입찰공고정보서비스 인증키

## 수동 실행
Actions → oda-watch → Run workflow (주말에도 보냄). 로컬: `FORCE=true python main.py` (텔레그램 설정이 없으면 out/에 파일만 만든다)
