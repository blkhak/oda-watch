| 해외건설협회 | 입찰공고, 공지사항, 보도자료, 국토교통 ODA, 최신정보, 건설뉴스 |

- 새 글이 하나도 없으면 PDF 없이 "해외사업 관련 추가 게시글 없습니다♥" 문구만 보낸다. 끝내 접속하지 못한 사이트가 있으면 "해외사업 관련 추가 게시글 없으나, ○○의 경우 접속이 되지 않아 직접 확인하셔야 합니다"와 그 사이트 바로가기 단추를 보낸다.
- 직전 보고 10분 전부터 겹쳐 조회하고, 이미 보낸 글(`state/seen.json`)은 뺀다. 주말·공휴일엔 건너뛰고 다음 보고에 몰아 담는다.
- 예약 실행은 40분 일찍 깨워 보고 시각까지 기다린다 (GitHub 예약 실행 지연 대비).
- 사이트 하나가 막혀도 나머지는 보고하고, 실패한 사이트는 보고서와 메시지에 표시한다.
- 나라장터 수요기관·남길 낱말·뺄 낱말은 `sources.py`의 `G2B_DEMAND`·`G2B_KEEP`·`G2B_INTERNAL`, 엔협 해외사업 판별은 `overseas.py`(국가명·해외·ODA 등 낱말)
- PDF 한글 글꼴: GitHub에선 나눔고딕(fonts-nanum), 윈도우에선 맑은 고딕

## 설정 (GitHub Secrets)
- `TELEGRAM_BOT_TOKEN` — 텔레그램 봇 토큰. 대화방(chat_id)은 봇에게 말을 건 방을 자동으로 찾아 `state/chat_id.txt`에 기억 (`TELEGRAM_CHAT_ID` Secret이 있으면 그것을 씀)
- `G2B_API_KEY` — 공공데이터포털 조달청 입찰공고정보서비스 인증키

## 수동 실행
Actions → oda-watch → Run workflow (주말에도 보냄). `test_days`에 14를 넣으면 최근 2주 치 시험 보고(기록은 안 바뀜). 로컬: `FORCE=true python main.py` (텔레그램 설정이 없으면 out/에 파일만 만든다)
